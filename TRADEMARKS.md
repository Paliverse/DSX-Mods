# The DSX name

DSX is Paliverse's controller app. The Apache-2.0 license here covers the code and the mod system only. It does not
license the DSX name or logo (Apache-2.0 section 6).

## You may

- Say your app, mod or tool **"works with DSX"**, is **"for DSX"** or **"uses the DSX Mod SDK"**, when that is true.
- Name DSX and link to it to describe what your work is compatible with.
- Use "DSX" in a mod's name after the mod's own name, to show what it works with (for example `WF2_DSX`).

## You may not

- Name an app or tool "DSX", or start its name with "DSX".
- Use the DSX logo or icon without written permission from Paliverse.
- Say or suggest that Paliverse made, endorses, sponsors or checked your app or mod.
- Call a modified copy or a reimplementation of the SDK, the protocol or the catalog "DSX".

## Credit

If you use the SDK, the protocol docs or the catalog tools, credit **"DSX by Paliverse"** in your docs, about box or notices.
For code, keeping the [NOTICE](NOTICE) file does this. A visible "Works with DSX" line in your app is welcome, not required.

Questions or permission requests: open an issue in this repository.
